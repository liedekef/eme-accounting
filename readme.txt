Single-entry accounting for Events Made Easy: accounts, journal, bank import, stock, depreciation, budget and reports.

== Description ==

EME Accounting extends Events Made Easy with single-entry accounting:

* Financial accounts and chart of accounts
* Journal (income, expenses and transfers)
* Bank statement import and reconciliation (CSV, MT940, CODA)
* Stock management
* Depreciation of assets
* Budgeting
* Financial reports (balance, results, cash flow) with charts
* Fiscal years and year-end closing

The plugin requires the Events Made Easy plugin.

== Installation ==

1. Install and activate the Events Made Easy plugin first.
2. Upload the `eme-accounting` folder to `/wp-content/plugins/` or install through WordPress.
3. Activate the plugin and configure it via Accounting in the admin menu.
